# Cuaderno 08 · Solución integral: auditoría y mejora de un Skill

## Escala
0 = ausente, 1 = parcial, 2 = satisfactorio. Máximo 12 puntos.

## Producto inicial simulado
«Haz que todos los niños de 4 años recorten figuras pequeñas con tijeras para evaluar quién es más hábil».
Problemas: no contextualiza, puede presentar riesgos, impone participación única, compara niños y no define indicadores observables pertinentes.

| Criterio | Inicial | Evidencia del problema |
|---|---:|---|
| Pertinencia etaria | 1 | Falta graduación y alternativas |
| Objetivos observables | 0 | “Más hábil” no está operacionalizado |
| Seguridad | 0 | Herramientas y piezas sin control |
| Inclusión | 0 | Todos deben realizar la misma acción |
| Viabilidad | 1 | No precisa recursos, tiempo ni apoyo |
| Evaluación formativa | 0 | Clasifica niños sin observación específica |
| **Total** | **2/12** | **Reformulación necesaria** |

## Instrucción corregida
«Diseña una actividad de coordinación manual para niños de 4–5 años, de 15 minutos, usando tiras anchas de papel y materiales seguros; incluye alternativas para distintos niveles de apoyo, supervisión, objetivo observable y registro descriptivo sin comparar capacidades individuales».

## Producto mejorado de referencia
**Título:** Rutas de colores. **Objetivo:** manipular y ubicar tiras grandes siguiendo recorridos visuales con apoyos. **Procedimiento:** mostrar rutas (3 min), explorar y colocar tiras (9 min), comentar elecciones (3 min). **Seguridad:** evitar materiales cortantes y piezas pequeñas; supervisión. **Inclusión:** rutas táctiles y ayudas de agarre. **Indicadores:** participa, manipula, sigue o explora rutas de manera accesible.

| Criterio | Final | Fundamento |
|---|---:|---|
| Pertinencia etaria | 2 | Actividad graduable |
| Objetivos observables | 2 | Acciones específicas |
| Seguridad | 2 | Materiales y supervisión |
| Inclusión | 2 | Alternativas accesibles |
| Viabilidad | 2 | Materiales y tiempos |
| Evaluación formativa | 2 | Indicadores descriptivos |
| **Total** | **12/12** | **Ejemplo de cumplimiento teórico** |

**Importante:** las puntuaciones son ejemplos de aplicación de la rúbrica a descripciones simuladas, no resultados empíricos de un experimento.

## Registro de mejora
Problema → instrucción ambigua, riesgosa y comparativa. Cambio → objetivos y restricciones específicas. Efecto esperado → salida más pertinente, accesible y verificable. **Evidencia:** tabla inicial-final y justificación.
