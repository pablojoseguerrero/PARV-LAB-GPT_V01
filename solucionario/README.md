## Uso didáctico
1. Solicita al participante completar el cuaderno correspondiente.
2. Contrasta el producto con la solución como **modelo**, no como respuesta única.
3. Revisa coherencia, seguridad, accesibilidad y pertinencia etaria.
4. Documenta mejoras; no utilices datos personales de menores.
5. Los resultados de prueba indicados son **esperados o simulados**, no ejecuciones verificadas en GPT.
