# Cuaderno 09 · Desafíos de autoaprendizaje
## Nivel 1
Construye un Skill para un cuento participativo sobre emociones.
## Nivel 2
Diseña otro Skill para juegos de clasificación con materiales reciclados seguros.
## Nivel 3
Elabora un Skill para revisar una planificación con criterios institucionales aportados por el usuario.
## Reto final
Documenta la arquitectura, tres pruebas, observaciones, límites y versión mejorada. No compartas datos personales de menores.
