# Cuaderno 02 · Markdown para construir habilidades
**Resultado:** documentar un procedimiento pedagógico.
## Ejercicio
Redacta en Markdown: # Nombre del Skill; ## Propósito; ## Entradas; ## Procedimiento; ## Validación. Usa listas con - y negritas con **.
## Desafío
Crea un archivo SKILL.md con metadatos name y description, y un procedimiento de cuatro pasos.
## Evidencia
Archivo de texto .md que pueda leerse y revisarse.
