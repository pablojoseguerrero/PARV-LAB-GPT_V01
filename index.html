Fundamentos interactivos

¿Qué es un LLM?

Un modelo de lenguaje de gran tamaño es una red neuronal entrenada para modelar patrones de secuencias de tokens. Al generar texto estima unidades sucesivas según su contexto. Puede equivocarse y necesita revisión humana.

Ensayo: compara «haz una actividad» con una solicitud que especifique edad, objetivo, recursos y duración.

Texto → tokens

Un token es una unidad definida por un tokenizador: puede corresponder a una palabra, parte de una palabra, puntuación u otra secuencia. La división depende del tokenizador.

Ejercicio: compara la longitud en palabras y tokens de dos instrucciones con el tokenizador del modelo elegido.

Markdown y .md

Markdown es un formato de texto ligero. Usa # para encabezados, - para listas y ** para negritas. Los archivos README.md documentan proyectos y SKILL.md describen habilidades.

Ejercicio: redacta un título, una lista de entradas y tres controles de calidad.

Asistentes, agentes, RAG y Skills

Asistente: ayuda en una conversación. Agente: organiza pasos y puede utilizar herramientas autorizadas. RAG: incorpora información recuperada de fuentes. Skill: empaqueta instrucciones, ejemplos y recursos reutilizables. Pueden complementarse.

Ejercicio: decide qué mecanismo necesitas para revisar una planificación institucional.
