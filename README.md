# PARV-LAB-GPT_V01

## Laboratorio de Skills Inteligentes con GPT para la Educación Parvularia
**Diseño y creación de herramientas inteligentes para el desarrollo integral y el aprendizaje infantil.**

Portal formativo de 90 minutos para docentes de grado y posgrado. Presentación web, fundamentos de LLM, tokens, Markdown, asistentes, agentes, RAG y Skills, cuadernos de práctica y construcción de Skills educativos.

### Recorrido
1. Fundamentos aplicados de inteligencia artificial.
2. Aprender a construir un Skill paso a paso.
3. Laboratorio PARV-EDU y aplicaciones para Educación Parvularia.
4. Validación pedagógica y retos de autoaprendizaje.
